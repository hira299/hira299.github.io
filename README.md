# hira299.github.io

Portfolio site for **Hira Ahmed** — AI Automation & QA Engineer.

## Stack

- Next.js (App Router) + TypeScript
- Static export for GitHub Pages
- MDX content under `content/`
- Source notes under `portfolio-source/`

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output is written to `out/` and deployed via `.github/workflows/deploy.yml`.
